# Photo Upload Guide

Use these folders for the current site placeholders.

## Team portraits

Folder: `assets/photos/team/`

Suggested filenames:
- `agent-01.jpg`
- `agent-02.jpg`
- `agent-03.jpg`
- continue the same pattern for more advisors

These will be linked into `team/index.html`.
